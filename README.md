# Smart\_Traffic\_using\_barricade



\## Project Overview



Smart Traffic Barricade is an Arduino-based smart traffic management system designed to control vehicle and pedestrian movement using automated traffic signals and servo-operated barricades.



\## Main Features



\- Automatic Red, Yellow and Green traffic signals

\- Dual servo motor barricade system

\- Servo movement restricted to 0°–90°

\- I2C LCD display

\- IR-based obstacle detection during barricade movement

\- Pedestrian and vehicle safety indication

\- Automated traffic cycle



\## Hardware Used



\- Arduino UNO

\- 2 × Servo Motors

\- Red LED

\- Yellow LED

\- Green LED

\- 16×2 I2C LCD

\- IR Sensor

\- Breadboard

\- Jumper Wires



\## Software



\- Arduino IDE

\- Arduino C/C++

\- LiquidCrystal\_I2C Library

\- Servo Library

\- Wire Library



\## Working



1\. At startup, all three LEDs turn ON and the project displays the team name.

2\. Red signal indicates that vehicles must stop and pedestrians can pass.

3\. Yellow signal indicates caution and activates the barricade movement.

4\. Green signal allows vehicles to pass and stops pedestrians.

5\. During barricade movement, the IR sensor checks for obstacles.

6\. If an obstacle is detected, the LCD displays an obstacle warning.

7\. The servo motors move only between 0° and 90° for safe operation.
